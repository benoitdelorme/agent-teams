# Demo: Milestone

A small project tracker the teams can work on: projects, tasks with a priority and a status, a progress overview, behind a login. Small enough to read in ten minutes, real enough that a feature touches an API contract, a schema, a screen and a test.

- [sample-backend](sample-backend/): the API, FastAPI + SQLite.
- [sample-frontend](sample-frontend/): the web app, React + Vite + Tailwind.
- `.teams/`: the instance, generated by `teams init sample-backend sample-frontend`. The two team purposes were edited by hand and the unedited role-prompt copies removed, so the demo always follows the engine's default prompts. On your own project `init` leaves those copies in `.teams/prompts/` for you to edit.

## Run the teams

```bash
cd examples/demo
teams up            # inside Programa or with tmux installed; without either it prints the commands to run yourself
```

Then give the manager a concrete outcome. Three that fit the codebase, from small to larger:

1. "Add a search box on the projects page that filters by name and description."
2. "Add due dates to tasks. Optional date on create and edit, shown on the task row, overdue tasks highlighted on the overview."
3. "Add project archiving. Archived projects disappear from the lists but stay reachable by id, with a way to restore them. Backend endpoint with tests, frontend controls with confirmation."

Each one needs an API contract between the two teams, which is what the protocol is for. Watch the tickets move on the board and read `.teams/shared/CONTRACTS.md` when it appears.

## Run the applications

The teams only need the source. Start the applications yourself when a task needs a running API or a browser check.

| Application | Setup | Start | Address |
| --- | --- | --- | --- |
| API | `cd sample-backend && uv sync` | `uv run uvicorn app.main:app --reload --port 8010` | `http://localhost:8010/docs` |
| Web app | `cd sample-frontend && pnpm install` | `pnpm dev` | `http://localhost:5173` |

Sign in with `admin@example.com` / `admin`. The frontend proxies `/api` to port 8010. The database is created and seeded on first start; delete `sample-backend/data.db` to reset it.

Tests: `uv run pytest` in the backend, `pnpm build && pnpm lint` in the frontend.
